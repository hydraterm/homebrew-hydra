# Hydra Homebrew tap

Install Hydra for macOS:

```sh
brew install --cask hydraterm/hydra/hydraterms
```

The cask downloads Hydra's immutable versioned DMG, verifies its pinned SHA-256 digest, and installs
`Hydra.app`. macOS continues to enforce the app's Developer ID signature, notarization, Gatekeeper,
and user-granted privacy permissions.
